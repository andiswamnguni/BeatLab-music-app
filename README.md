BeatLab Music Player

BeatLab is a modern, all-in-one music player that brings together streaming, song identification, and DJ features in one powerful app. It’s built with React and Tailwind CSS to deliver a fast, beautiful, and responsive experience.

Features
Core Music Experience

Smart Search – Find songs, artists, and albums through the Deezer API

Trending Music – Explore the latest and most popular tracks on the home screen

Music Playback – Stream 30-second previews with full player controls

Grid Layout – Clean, card-based interface for easy browsing

Song ID Recognition

Instant Identification – Use your device microphone to recognize songs playing nearby

One-Tap Integration – Add identified songs straight to your playlists or favorites

Real-World Use – Ideal for taxis, parties, shops, or any setting where music is playing

Seamless Experience – Everything happens inside BeatLab, no need to switch apps

Professional DJ Console

Dual Deck System – Two decks for live mixing

BPM Control – Adjust tempo with precision

Crossfader – Smooth transitions between tracks

Direct Playback – Stream songs without downloading

Artist Support – Legal streaming ensures artists are fairly compensated

Personal Library

Playlist Management – Create, edit, and organize your own playlists

Favorites – Save and quickly access your top tracks

Smart Organization – Manage songs with simple drag-and-drop controls

Modern Design

Mobile-First – Optimized for mobile use with accessible navigation

Dark Theme – Designed with soft gradients that are easy on the eyes

Fixed Navigation – Keep player controls always visible

Responsive Layout – Works smoothly across all screen sizes

Tech Stack

Frontend Framework: React 18

Build Tool: Vite

Styling: Tailwind CSS

Routing: React Router DOM

Music API: Deezer API

Audio: HTML5 Audio API

State Management: React Context API and useState

Why BeatLab?
The Problem

Most music apps require switching between multiple platforms for streaming, song identification, and DJ tools. BeatLab solves this by combining everything into one integrated experience.

All-in-One Solution – No need to use separate apps like Shazam or standalone players

DJ-Ready – Equipped with tools for both beginner and professional DJs

Artist-Friendly – Built on a legal streaming model that supports creators

User-Centered – Designed for real-world music discovery and interaction

Real-World Scenarios

In a taxi – Identify and save songs instantly

At a party – Mix and play music directly from your phone

While shopping – Discover and add new tracks to your collection

At home – Explore trending music and build the perfect playlist
